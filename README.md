 [C++](https://img.shields.io/badge/C++-Programming-blue)
 [BCA](https://img.shields.io/badge/BCA-1st%20Semester-green)

A menu-driven C++ toolkit with 5 beginner-friendly tools built for BCA 1st Semester.

 Features
1. **Triangle Checker** - Identifies Equilateral/Isosceles/Scalene using nested if-else
2. **Calculator (If-Else)** - Basic arithmetic operations with if-else ladder
3. **Calculator (Switch-Case)** - Same logic implemented using switch-case  
4. **Sum of N Numbers** - Calculates sum of first N natural numbers using loops
5. **LoopSum** - Add N user-entered numbers with dynamic input

 Concepts Covered
`Loops` `If-Else` `Switch-Case` `Functions` `User Input` `Menu-Driven Program`

 How to Run
```bash
g++ toolkit.cpp -o toolkit
./toolkit
